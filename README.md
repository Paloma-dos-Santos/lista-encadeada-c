# lista-encadeada-c
# Lista Encadeada em C

## Descrição
Implementação de uma lista encadeada dinâmica em linguagem C, com operações básicas de inserção, remoção, busca e exibição de elementos.

## Funcionalidades
- Inserção no início da lista
- Inserção no fim da lista
- Inserção em posição específica
- Remoção no início
- Remoção no fim
- Remoção por posição
- Busca de elementos
- Impressão da lista
- Liberação de memória

## Conceitos aplicados
- Ponteiros
- Alocação dinâmica (malloc e free)
- Estruturas de dados
- Manipulação de memória

## Linguagem
C
